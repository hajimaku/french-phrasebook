# フランス語 旅の会話帳

ニース中心の一人旅（モナコを含む）で使う、日本語話者向けのフランス語フレーズブックです。
紙の旅行会話集のように「目次から場面を選び、必要な表現を探す」ことを中心にした、iPhone 向けの Web アプリ（PWA）です。
姉妹版の「ドイツ語 旅の会話帳」（hajimaku/german-phrasebook）と同じ仕組みで作っています。

- アカウント登録・バックエンド・有料 API・生成 AI は使いません。フレーズはすべて事前に収録しています。
- 一度読み込めば、機内モードでも全フレーズ・検索・お気に入りが使えます。フォントもアイコンも外部から読み込みません。
- ビルドは不要です（HTML / CSS / JavaScript のみ）。

## 収録内容

| 項目 | 件数 |
|---|---|
| カテゴリー | 17（必須／伝わらない／空港／鉄道・トラム・バス／ホテル／レストラン／カフェ・パン屋／ワインバー・アペロ・バー／アレルギー／買い物／観光・写真（モナコ含む）／海辺・ビーチ／マルシェ／道案内／緊急／数字・表示／交流） |
| フレーズ | 349（読み方・使い方・検索語・重要度付き） |
| 必須フレーズ | 30 |
| 入れ替え表現 | 51（冠詞・前置詞・性数一致が変わるものは完成文を個別に収録） |
| 相手の返事 → 次に言うこと | 50 フレーズに付属 |
| よく聞かれること（→ こう答える） | 34 |
| 会話例（2〜4往復・全文日本語訳付き） | 28 |

地域ラベル：`ニース・南仏`（ソッカ、パン・バニャ、ベレのワインなど）、`モナコ`（カジノ、大公宮殿など）。

## 起動方法

```sh
npm start            # http://127.0.0.1:8000/ （依存パッケージなしで動く）
```

Node.js がない場合は `python3 -m http.server 8000` でも動きます。

### iPhone で使うには

オフライン保存（Service Worker）は **https** または **localhost** でのみ動きます。
GitHub Pages（Settings → Pages → Branch: `main` / `(root)`）で公開すると
`https://hajimaku.github.io/french-phrasebook/` で使えます。

1. iPhone の Safari で公開 URL を開く
2. 目次の上に「オフライン準備完了」と表示されるのを待つ
3. 共有ボタン →「ホーム画面に追加」
4. ホーム画面のアイコンから開き、機内モードで目次・検索が動くことを確かめる

### ドイツ語版と同じドメインで公開する場合

両方とも `hajimaku.github.io` で公開すると、キャッシュとブラウザ内保存がドメイン単位で共有されます。
そのため、このアプリはキャッシュ名に `pb-fr-`、保存キーに `pb-fr.` を付けて区別し、ドイツ語版のデータを消したり混ぜたりしないようにしています。
ドイツ語版の `sw.js` を今後更新するときは、同じように自分のキャッシュだけを削除する形にしてください。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 画面の骨組み・アイコン（インライン SVG） |
| `css/app.css` | 見た目（端末内フォントのみ、ライト／ダーク対応） |
| `js/app.js` | 画面遷移、見せるモード、お気に入り、入れ替え、読み上げ（fr-FR）、オフライン状態表示 |
| `js/search.js` | 全文検索（かな・全角半角・大文字小文字・アクセント記号の省略・œ/oe・アポストロフィ・関連語） |
| `data/core.js` | データ形式の定義と正規化（「 ? 」などの前の空白は改行しない空白に変換） |
| `data/phrases-1.js`〜`phrases-4.js` | 17カテゴリーのフレーズ |
| `data/conversations.js` | よく聞かれること・会話例 |
| `sw.js` | 全ファイルを事前キャッシュする Service Worker |
| `manifest.webmanifest`, `icons/` | ホーム画面用の設定とアイコン（青） |
| `tools/` | 開発用（サーバー・検証・E2E・アイコン生成）。公開は不要 |

## データ形式

各フレーズは次の項目を持ちます（詳細は `data/core.js` の先頭）。

`id` / `category` / `scene` / `ja`（日本語の意味） / `fr`（フランス語） / `kana`（読み方の目安） /
`note`（使う場面・丁寧さ） / `keywords`（検索用） / `importance`（1〜3） / `first`（まず使う表現） /
`essential`（必須ページ） / `region`（地域ラベル） / `replies`（相手の返事と次に言うフレーズ） /
`alternatives`（ほかの言い方・女性形など） / `slot`（入れ替え）

## 検証

```sh
npm run validate     # データ検証：ID重複・必須項目・入れ替え文・検索・キャッシュ対象の漏れ
npm run test:e2e     # ブラウザ動作確認（Playwright。npm install が必要）
npm test             # 両方
```

フレーズやファイルを変更したら、`sw.js` の `VERSION` を上げてください（利用者の端末のキャッシュが更新されます）。
